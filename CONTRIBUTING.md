# Contributing

Bugs, feature ideas, and pull requests are all welcome.

## Reporting Issues

Open a [GitHub issue](https://github.com/savitojs/Gurbani-Live/issues). Include your OS, shell, and the output of `gurbani-live --version`.

## Pull Requests

1. Fork the repo and create a branch
2. Make your changes
3. Run `bash -n gurbani-live` to check syntax
4. Test `--version`, `--help`, `--status` at minimum
5. Submit a PR with a clear description of what changed and why

## Code Style

- Keep it readable. Descriptive variable names, short functions.
- Use `shellcheck` if you have it.
- Write clear commit messages.

## Testing

See [docs/TESTING.md](docs/TESTING.md) for how to test the CI/CD workflows locally.
